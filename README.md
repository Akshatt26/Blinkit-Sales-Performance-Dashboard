# 🛒 Blinkit Sales Performance Dashboard

An interactive Power BI dashboard designed to analyze Blinkit's sales performance, customer satisfaction, and inventory distribution. The dashboard transforms sales data into actionable business insights using KPIs, interactive filters, and data visualizations.

---

## 1. Project

### 🛒 Blinkit Sales Performance Dashboard

A dynamic and interactive Power BI dashboard developed to analyze Blinkit's sales performance across different product categories, fat-content segments, outlet types, outlet sizes, outlet locations, and establishment years.

The dashboard provides a consolidated view of key business metrics and enables users to identify sales trends, product performance, and outlet-level opportunities.

---

## 2. Description

The **Blinkit Sales Performance Dashboard** is a Power BI analytics project developed to evaluate sales performance, customer satisfaction, and inventory distribution.

The dashboard enables users to analyze key business KPIs such as **Total Sales, Average Sales, Number of Items, and Average Rating**, while providing detailed analysis across product and outlet dimensions.

The goal is to transform raw sales data into meaningful business insights that can support **data-driven decision-making and performance optimization**.

---

## 3. Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Microsoft Power BI Desktop** – Main platform used for dashboard development and data visualization.
- 📂 **Power Query** – Used for data cleaning, transformation, and preparation.
- 🧠 **DAX (Data Analysis Expressions)** – Used to create calculated measures and KPI metrics.
- 🗂️ **Data Modeling** – Used to structure the data for efficient analysis and visualization.
- 📈 **Data Visualization** – KPI cards, donut charts, bar charts, line charts, tables, and interactive slicers.
- 📁 **File Format** – `.pbix` for the Power BI project and `.png` for the dashboard preview.

---

# 4. Business Requirement

The objective of this project is to conduct a comprehensive analysis of **Blinkit's sales performance, customer satisfaction, and inventory distribution** to identify key insights and opportunities for optimization using KPIs and visualizations in Power BI.

### Key Performance Indicators

The dashboard focuses on four primary KPIs:

| KPI | Description |
|---|---|
| 💰 Total Sales | Overall revenue generated from all items sold |
| 📊 Average Sales | Average revenue generated per sale |
| 📦 Number of Items | Total number of items sold |
| ⭐ Average Rating | Average customer rating for items sold |

# 5. Data Source

The project uses a Blinkit sales dataset containing information related to products, sales, outlets, locations, customer ratings, and other business attributes.

The dataset supports analysis across:

- Item Type
- Item Fat Content
- Outlet Type
- Outlet Size
- Outlet Location Type
- Outlet Establishment Year
- Item Visibility
- Item Sales
- Customer Rating

The data was cleaned and transformed using **Power Query** before being modeled and analyzed in Power BI.

> **Note:** The dataset is used for educational and portfolio purposes to demonstrate data analytics and business intelligence skills.

# 6. Features

## 🔹 Business Problem

Retail businesses generate large amounts of sales data across products, outlets, and locations. Analyzing this data manually can make it difficult to quickly identify sales trends, high-performing products, and outlet-level opportunities.

This dashboard addresses these challenges by providing an interactive view of Blinkit's sales performance and allowing users to analyze business metrics across multiple dimensions.

### Key Business Questions

- Which product categories generate the highest sales?
- How does fat content affect total sales?
- Which outlet types contribute the most to revenue?
- How does outlet size influence sales?
- Which outlet locations generate the highest sales?
- How have sales changed across outlet establishment years?
- How do average sales, number of items, and ratings vary across different segments?

---

## 🎯 Goal of the Dashboard

The primary goal of the dashboard is to provide an interactive analytical tool that:

- Evaluates overall sales performance.
- Tracks key business KPIs.
- Analyzes customer satisfaction through average ratings.
- Identifies high-performing item categories.
- Evaluates the impact of fat content on sales.
- Compares performance across outlet types and sizes.
- Analyzes sales distribution across outlet locations.
- Identifies sales trends based on outlet establishment.
- Supports data-driven business decisions.
